Cisco IOS Configuration Guide

Copy/Paste to your GNS3 Cisco IOS device console to enable TACACS+ Authentication & Command Authorization:

! Define TACACS+ server
tacacs-server host 192.168.1.2 key tacsecret

! Enable AAA authentication, authorization & accounting
aaa new-model
aaa authentication login default group tacacs+ local
aaa authorization exec default group tacacs+ local
aaa authorization commands 15 default group tacacs+ local
aaa accounting exec default start-stop group tacacs+
aaa accounting commands 15 default start-stop group tacacs+

Shared File Manager (TFTP / FTP / SFTP)

This appliance runs TFTP (UDP 69), FTP (TCP 21), and SFTP (TCP 22) servers. All file transfers are mapped to a central directory /var/lib/netlab/files. Use this directory to backup configuration files, save IOS images, or transfer licenses.

Upload File to Appliance
Cisco IOS Configuration Examples: # Save configuration to TFTP:
copy running-config tftp://<appliance-ip>/running-config.txt # Save configuration to FTP (Anonymous):
copy running-config ftp://anonymous@<appliance-ip>/running-config.txt # Save configuration to SFTP (Root User):
copy running-config sftp://root:netlab@<appliance-ip>/running-config.txt
